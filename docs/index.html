Why this exists

Teams decide an AI is safe to put near their data using one number: how often it gets the answer right. That number cannot tell you whether anyone would notice when it is wrong. A model that fails loudly at 80 percent accuracy is safer than one that fails silently at 90.

So this study measures the second thing, with the hypothesis and the statistics committed to version control before any data was collected.

What this is

Companies now let AI write . When it gets one wrong, it rarely breaks. The query runs fine and quietly returns wrong numbers, and those numbers go into somebody's report.

So I had AI write 600 queries, ran every one against a real database, and checked them against human answers. Then I counted how many of the wrong ones anybody could have spotted.
