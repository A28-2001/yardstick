Can you tell which SQL is wrong?

Aakash Mehta Email LinkedIn Code and data Full write-up

Companies are starting to let AI write . When it gets one wrong, you would hope it breaks loudly. Usually it does not. The query runs perfectly and quietly returns the wrong numbers, and those numbers go into somebody's report.

So I had AI write 600 database queries, ran every single one against a real database, and compared the answers against ones written by humans. Then I checked something more useful than accuracy: when it was wrong, could anyone tell?

Start with the quiz below. After that you can filter all 600 runs, or query the results in SQL yourself. Everything on this page is real data from the study, not an illustration.
